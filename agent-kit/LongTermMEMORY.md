# Long-Term Memory — Walkthrough Lessons

> Format: cue → lesson → evidence → confidence, one or two lines each. Only lessons not already in `../docs/METHOD.md`. Append 1–3 per run; never paste logs.
> Product names are anonymised in this distributed copy: "client A" = a reviewed Electron client, "client B" = another one.

- **cue**: permission dialog with "always allow for this session" → **lesson**: keep operating after choosing it; if the same prompt returns, that is a finding—screenshot both times. **evidence**: client A deep research, ≥3 prompts in one task. **confidence**: medium-high.
- **cue**: using the tool's own research output as evidence → **lesson**: run the same capability twice; one wrong + one right means unstable, not fixed. **evidence**: two reports on the same product contradicted each other on platform support. **confidence**: high.
- **cue**: evaluating first-run experience → **lesson**: re-check the home screen after login; promos or credit offers may only appear then, so the login page is not the first-run impression. **evidence**: client A login page clean, post-login home had two credit promos. **confidence**: high.
- **cue**: driving a windowed app through CDP → **lesson**: let the harness own the screenshots — `wt.py click` shoots right after the click and `cdp.py ... --capture` does the same; a separate window-capture helper bypasses `events.jsonl` and leaves `click -> shot` WARNs. **evidence**: client C run 2026-10-22, 3 unpaired CDP clicks, fixed in the same run by adding click-time capture. **confidence**: high.
- **cue**: building the page map → **lesson**: a page map is a crawl, not a screenshot; menus, tabs and dialogs only exist after you open them, so click through the product before designing tasks, and record the nav edge each time. **evidence**: client C 2026-10-22, the first-screen map missed the whole File menu; opening it revealed a menu with a single item, which became finding F7. **confidence**: high.
- **cue**: shipping a report PDF → **lesson**: check what gets embedded; receipts/QR codes and account names need pixel-level redaction (`--redact` or `captions.json`), and unreferenced screenshots should stay out of the PDF. **evidence**: client C 2026-10-22, a payment QR reached the PDF while the text claimed it was excluded. **confidence**: high.
- **cue**: agent shell launches an Electron app and it exits immediately (exit 9, or `--version` prints a Node version) → **lesson**: the session env probably carries `ELECTRON_RUN_AS_NODE=1`; clear it for the child process before relaunching, and log the env fact under method, not findings. **evidence**: Qoder CN 0.4.9 2026-10-23, 12 processes died on launch, CDP only came up after `Remove-Item Env:ELECTRON_RUN_AS_NODE`. **confidence**: high.
- **cue**: a menu opens but CDP text/screenshot shows nothing, and UIA finds no menu window → **lesson**: Electron native menus live outside the page and outside the UIA tree; open them with a real mouse and read a desktop screenshot, then enumerate items by eye. Same for legacy folder pickers: set the path with `WM_SETTEXT` on the `Edit` child and confirm with `BM_CLICK` on button id 1. **evidence**: Qoder CN 0.4.9 2026-10-23, all four top menus + the workspace picker. **confidence**: high.
- **cue**: renaming or pruning `screens/*.png` after a crawl → **lesson**: `events.jsonl` stores absolute screenshot paths, so renames turn `audit` into `shot files FAIL / N missing`; freeze the S-number naming before the first capture, or keep a copy under the old path. **evidence**: Qoder CN 2026-10-23, 28 missing after renaming; fixed by restoring aliases, not by rewriting the log. **confidence**: high.
- **cue**: automating a desktop agent that must switch projects per task → **lesson**: in Qoder the workspace chip is `cursor-not-allowed` inside a task; go to 「新的任务」 first, then click the chip, then 「新建工作区」. Creating one workspace per fixture (rather than one shared root) keeps tasks from seeing each other's solutions. **evidence**: code-eval 2026-10-26, 10 fixtures × 3 reps driven this way. **confidence**: high.
- **cue**: a PowerShell helper with Chinese window titles is invoked by `powershell.exe` → **lesson**: write the `.ps1` as UTF-8 **with BOM**; PS 5.1 reads a BOM-less file as ANSI and the literals turn to mojibake, which fails at parse time. Matching the dialog by owning process + class `#32770` also survives title changes. **evidence**: 2026-10-26 Qoder folder picker; first version died with `Unexpected token`. **confidence**: high.
