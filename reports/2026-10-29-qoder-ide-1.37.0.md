# Qoder IDE 1.37.0 核心链路走查

- 日期：2026-10-29
- 产品：Qoder IDE 1.37.0（`qoder-ide` Debian 包）
- 环境：Ubuntu 26.04 / GNOME Wayland + XWayland / `DISPLAY=:0` / 1440×900 / CDP 9361
- 工作区：`/tmp/qoder-ide-lab`
- 方式：真实桌面窗口 + CDP
- 范围：核心 IDE 链路，不是完整功能矩阵

## 结果

**核心编辑器和 Agent 链路可用。**

- 真实 IDE 工作台：Explorer、编辑器、终端、Agent 面板齐全
- 打开工作区后，文件树显示 `tests/`、`calculator.py`
- 编辑器读取 `calculator.py`，状态栏显示 Python 3.14.7
- Agent 修复 `add`：`a - b` → `a + b`，只改 1 个文件、`+1/-1`
- 独立 `python3 -m unittest discover -s tests -v`：**2/2 OK**
- 接受修改后 `Edits Kept`，Git 状态显示 `calculator.py` 已修改

## 观察

1. **`Ctrl+`` 没有打开终端**
   - 通过命令面板 `Terminal: Create New Terminal` 才打开；终端 cwd 正确。
2. **`Run in terminal` 会先弹自动执行确认**
   - 属于安全设计，但会打断“一键跑测试”的预期。
3. **当前环境没有硬件图形加速**
   - 启动日志提示 `Hardware graphics acceleration is not available`；不是虚拟显示，但会影响编辑器流畅度，性能结论受限。
